# gtfs-lint

This project was renamed to [`gtfs-validator`](https://pypi.org/project/gtfs-validator/).

`gtfs-lint` is kept as an alias so that `pip install gtfs-lint` keeps working. It
contains no code of its own: installing it installs `gtfs-validator`, which
provides the `gtfs-validator` command.

Use `gtfs-validator` directly in anything new.
